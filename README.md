# Cosmetic Armor

Standalone Minecraft Forge 1.18.2 mod by Vonix.Network.

This mod adds a cosmetic armor wardrobe directly to the vanilla inventory screen. It is intentionally separate from XP Skill Tree.

## Features

- Inventory-integrated cosmetic controls
- Toggle cosmetic armor on/off
- Assign main-hand armor to Boots, Legs, Chest, or Helm cosmetic slots
- Clear individual slots
- Cosmetic state persists with the player
- Cosmetic items are visual-only and do not replace or consume equipped armor

## Build

Requires Java 17:

```bash
JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64 ./gradlew clean build
```

Artifact: `build/libs/cosmetic-armor-forge-1.18.2-1.0.0+1.18.2.jar`
